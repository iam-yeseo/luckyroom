# 운빨 실험실

오늘의 순수한 운을 시험하는 한국어 확률 게임 아케이드입니다.

## 게임

- **로또 맞히기** — 1~45 중 6개를 선택한 뒤 6개 본번호와 보너스 번호를
  하나씩 추첨합니다. 실제 로또 6/45의 1~5등 판정 규칙을 따릅니다.
- **즉석김밥1000** — 행운 숫자와 나의 숫자 6칸을 직접 긁습니다. 스피또1000
  기본 발행 단위 500만 장의 등급별 수량을 같은 비율로 반영했습니다.

두 게임 모두 실제 복권 구매나 당첨금 지급과 무관한 무료 시뮬레이션입니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열면 바로 플레이할 수 있습니다.

## 검증

```bash
npm test
```

빌드, 서버 렌더링, 로또 등수 판정, 중복 없는 추첨, 즉석복권 티켓 불변식과
500만 장 확률표 합계를 함께 확인합니다.
