# 운빨 실험실

코인을 쓰고 벌며 일곱 가지 게임을 즐기는 한국어 운빨 아케이드입니다.
로그인 없이 바로 시작할 수 있으며 지갑, 저장한 운, 주식 보유 내역은
브라우저별 익명 계정에 저장됩니다. 쿠키를 삭제하거나 다른 브라우저를 사용하면
새 지갑으로 시작합니다. 모든 코인은 게임 속 가상 재화이며 실제 금전 가치가
없습니다.

## 코인 경제

- 처음 가입하면 `1,000,000 C`가 지급됩니다.
- `랜덤 C 받기`는 10초마다 1~1,000,000 C를 무작위로 지급합니다.
- `운 저장하기`로 원하는 코인을 되돌릴 수 없는 운 기록으로 전환합니다.
- 모든 게임 구매, 당첨금, 주식 거래가 하나의 지갑과 거래 내역에 연결됩니다.

## 게임

- **로또 맞히기** — 1게임 1,000 C, 한 회차에 최대 5게임. 회차별 당첨금은
  기본 금액의 ±10%이며 1~3등은 누진 기타소득세를 공제합니다.
- **즉석김밥 1000 / 2000** — 두 가격대의 독립된 당첨금·확률표를 적용한
  즉석 긁기 게임입니다.
- **추억의 종이뽑기판** — 10×16, 총 160장의 공유 뽑기판입니다. 3~5초마다
  다른 손님이 한 장을 뽑아가며 모두 사라지면 무작위 새 판으로 교체됩니다.
- **주식 투자하기** — 일반주 10종목과 사성전자·아이닉스·GAVER의 2배·3배
  레버리지/인버스 12종목이 5초마다 변동합니다. 최저가, 거래정지,
  상장폐지와 재상장 상태를 포함합니다.
- **행운 경마장** — 매번 무작위로 뽑힌 출전마 12마리 중 한 마리에
  배팅하고, 30초 실시간 집계와 경주를 거쳐 1~3위 상금을 나눠 받습니다.
- **AI 가위바위보** — 3판 2선승·5판 3선승·7판 5선승 중 하나를 고르고
  최소 1,000 C를 배팅합니다. AI는 플레이어 배팅의 ±25%를 걸며, 최종
  승리하면 AI 배팅금을 가져갑니다.
- **타이밍의 신** — 3.00·5.00·7.77·10.00·10.01초 중 하나를 고른 뒤
  스톱워치를 소수점 둘째 자리까지 정확히 멈춥니다. 연속 실패할 때마다 다음
  배수가 0.1배씩 오르고 성공하면 1.1배로 초기화됩니다.

## 실행과 검증

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
npm test
```

`npm test`는 배포 빌드와 로또·세금·즉석김밥·종이뽑기·주식·경마·
가위바위보·타이밍 게임 불변식을 검증합니다. 데이터 구조 변경 시
`npm run db:generate`로 D1 마이그레이션을 생성합니다.

Cloudflare Workers Builds에서는 `CLOUDFLARE_D1_DATABASE_ID`와
`CLOUDFLARE_D1_DATABASE_NAME`을 빌드 변수로 지정합니다. 전자는 D1에서
발급된 UUID, 후자는 연결할 데이터베이스 이름입니다.
